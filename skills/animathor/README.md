# Animathor — Unified Manim Animation Studio Skill 🎬📐

> **Official Registry Entry for `skills.sh`**

Animathor is an autonomous AI agent skill for mathematical, algorithmic, and scientific animation video production built on Manim Community Edition and ManimGL.

---

## 📦 Installation via `skills.sh`

Add Animathor to any AI coding agent project (Claude Code, Cursor, Windsurf, Codex, Gemini):

```bash
npx skills add <username>/animathor
```

Or install using the direct `skill.sh` installer:
```bash
# On Linux / macOS / Git Bash:
curl -fsSL https://raw.githubusercontent.com/<username>/animathor/main/skill.sh | bash

# Or locally:
bash skill.sh install
```

On Windows PowerShell:
```powershell
.\skill.ps1 install
```
